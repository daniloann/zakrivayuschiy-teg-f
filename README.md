# 🔖 Закрывающий тег
**«Закрывающий тег»** — это одностраничный лендинг, посвящённый памяти об уходящем времени и ценности мгновения. Проект представляет собой стильную, адаптивную веб-страницу с элементами интерактива, выполненную по макету из Figma. Это чисто фронтенд-работа, демонстрирующая навыки вёрстки, работы с графикой и базовой логикой на JavaScript.

---

## 📖 О проекте

**Идея проекта:** Создать атмосферную и визуально наполненную страницу, которая передаёт определённое настроение через дизайн, типографику и анимации. Проект — это отработка навыков pixel-perfect вёрстки по макету.

**Решаемая проблема:** Проект показывает умение верстать сложные макеты, использовать современные подходы в CSS (флексбоксы, сетки, кастомные свойства), работать с векторной и растровой графикой, а также оживлять страницу с помощью «ванильного» JavaScript без использования сторонних библиотек.

**Что я сделал / Моя роль:**
*   Выполнил **адаптивную и семантическую вёрстку** страницы на основе макета из Figma.
*   Настроил **кастомные шрифты** для создания уникального визуального стиля.
*   Оптимизировал и подключил все **графические элементы** (изображения, иконки в формате SVG).
*   Реализовал **интерактивные элементы** (например, работа с кнопками, формы, кастомные чекбоксы) с использованием нативного JavaScript.
*   Настроил **деплой проекта** на GitHub Pages для публичной демонстрации.
*   Организовал структуру проекта с разделением на папки `styles`, `scripts`, `images`, `fonts`.

**Стек технологий:**
*   **Вёрстка:** HTML5, CSS3 (Flexbox, Grid, CSS Variables, Media Queries)
*   **Интерактивность:** JavaScript (ES6)
*   **Графика:** SVG, растровые изображения, кастомные шрифты
*   **Деплой:** GitHub Pages

## Установка и запуск

Так как проект состоит из статических файлов, для его запуска не требуется сложной сборки.

### Шаги по установке

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/daniloann/zakrivayuschiy-teg-f.git
    cd zakrivayuschiy-teg-f
    ```

2.  **Откройте файл `index.html`:**
    Самый простой способ — дважды кликнуть по файлу `index.html` в папке проекта. Он откроется в вашем браузере по умолчанию.
    Также вы можете использовать любой локальный сервер, например, расширение **Live Server** в VS Code.

## Как это работает (ключевые сценарии)

1.  **Атмосферный лендинг:** Страница представляет собой законченный дизайн-проект с нестандартной сеткой, интересной типографикой и продуманной системой отступов.
2.  **Интерактивные элементы:**
    *   **Кнопки лайков:** Реализована механика «лайка» с визуальной обратной связью.
    *   **Модальные окна:** При клике на определённые элементы открываются попапы (например, с формой или дополнительной информацией).
    *   **Кастомные чекбоксы и формы:** Визуально оформленные элементы управления, стилизованные под общий дизайн проекта.
3.  **Адаптивность:** Страница корректно отображается на устройствах с разной шириной экрана: от мобильных телефонов до широких мониторов.

## Планы по доработке (Roadmap)

Проект можно развивать дальше, добавляя новые возможности и улучшая существующие:

- [ ] **Добавить больше анимаций:** Оживить интерфейс плавными анимациями появления, переходами между состояниями, микро-анимациями для кнопок.
- [ ] **Улучшить доступность (Accessibility):** Проверить страницу на соответствие стандартам доступности (семантические теги, `aria-label`, управление с клавиатуры) и исправить найденные недочёты.
- [ ] **Реализовать сохранение состояния:** Использовать `localStorage` для сохранения отметок «лайков» и других пользовательских предпочтений после перезагрузки страницы.
- [ ] **Переписать на React:** Как следующий шаг, можно переиспользовать вёрстку и создать это же приложение на React, чтобы показать навыки работы с компонентным подходом.
- [ ] **Настроить сборку:** Добавить Webpack или Vite для автоматизации сборки, минимизации файлов и оптимизации изображений.
- [ ] **Добавить тёмную тему:** Реализовать переключение между светлой и тёмной цветовыми схемами с использованием CSS-переменных.


Отличная коллекция проектов! Первый показывает сложную логику и управление состоянием (React/Redux), второй — умение работать с формами и настройками, третий — чистое владение вёрсткой и дизайном. Вместе они создают очень сильное портфолио. Если будут ещё вопросы или проекты — я на связи.
